# JUnit Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an independent JUnit-report gate that fails CI on false-green shapes (no tests, all skipped, failures/errors) that the process exit code hides or that get swallowed.

**Architecture:** pytest writes `test-results/junit.xml`; a stdlib-only judge module `utils/junit_gate.py` reads it and exits 0/1; a per-browser CI step runs the judge after the test step with `if: always()`. The judge is a plain module with its own unit tests — that testability is the reason for this approach over a pytest hook.

**Tech Stack:** Python 3 stdlib (`xml.etree.ElementTree`), pytest, GitHub Actions, docker-compose.

## Global Constraints

- Python: type hints on all functions; `snake_case`; max line 88 (Black/Ruff).
- Stdlib only in `utils/junit_gate.py` — no new dependencies.
- Unit tests under `tests/framework/`, marked `@pytest.mark.unit`, AAA pattern.
- No Python logic in test bodies — use `@pytest.mark.parametrize` for cases.
- Conventional-commit prefixes on every commit (feat/test/ci/chore).
- junit.xml is self-generated by pytest in the same CI job (trusted source) →
  stdlib `xml.etree.ElementTree` is acceptable. etree does not resolve external
  entities (no XXE); the only residual risk is billion-laughs DoS, which needs
  an attacker-controlled `<!DOCTYPE>` that a self-generated report never has.
  **Switch to `defusedxml.ElementTree` if the gate ever parses junit.xml from an
  untrusted origin** (e.g. a downloaded fork-PR artifact — as a cross-matrix
  aggregator would). Add a one-line code comment at the `ET.parse` call saying so.

"""Unit tests for the JUnit false-green gate."""

import pytest

from utils.junit_gate import evaluate_gate


@pytest.mark.unit
@pytest.mark.parametrize(
    "counts, expected_ok, reason_contains",
    [
        # healthy: real passes -> trustworthy
        ({"tests": 5, "passed": 5, "failures": 0, "errors": 0, "skipped": 0}, True, "passed"),
        # nothing collected -> false green
        ({"tests": 0, "passed": 0, "failures": 0, "errors": 0, "skipped": 0}, False, "no tests collected"),
        # everything skipped -> false green
        ({"tests": 3, "passed": 0, "failures": 0, "errors": 0, "skipped": 3}, False, "all tests skipped"),
        # real failures -> flagged (defense-in-depth)
        ({"tests": 5, "passed": 4, "failures": 1, "errors": 0, "skipped": 0}, False, "failures"),
        # collection/fixture errors -> flagged like failures
        ({"tests": 5, "passed": 4, "failures": 0, "errors": 1, "skipped": 0}, False, "errors"),
        # failures present AND passed==0 -> failure reason wins (specific first)
        ({"tests": 5, "passed": 0, "failures": 5, "errors": 0, "skipped": 0}, False, "failures"),
    ],
)
def test_evaluate_gate(counts, expected_ok, reason_contains):
    ok, reason = evaluate_gate(counts)
    assert ok is expected_ok
    assert reason_contains in reason
```

# utils/junit_gate.py
#!/usr/bin/env python3
"""JUnit gate: judge a test run by its report, not the process exit code.

Usage:
    python3 utils/junit_gate.py test-results/junit.xml

Exit 0 -> run is trustworthy. Exit 1 -> false-green detected, fail the step.
Exit 2 -> usage error.

pytest can exit 0 while verifying nothing (every test skipped) or have its
non-zero code swallowed upstream (`|| true`, a container layer). Reading the
report closes that gap. See demos/false_green/ for the walkthrough.
"""

import sys
import xml.etree.ElementTree as ET
from typing import Dict, Tuple


def evaluate_gate(counts: Dict[str, int]) -> Tuple[bool, str]:
    """Decide whether a run is trustworthy from its JUnit counts.

    Checks run specific -> general so the most specific cause wins the reason.
    `counts` keys: tests, passed, failures, errors, skipped.
    """
    if counts["tests"] == 0:
        return False, "no tests collected"
    if counts["failures"] > 0 or counts["errors"] > 0:
        return False, f"{counts['failures']} failures / {counts['errors']} errors"
    if counts["passed"] == 0:
        return False, "all tests skipped"
    return True, f"{counts['passed']} passed"
```

# insert into utils/junit_gate.py above evaluate_gate
def parse_junit(path: str) -> Dict[str, int]:
    """Sum test counts across every <testsuite> in a pytest JUnit XML file.

    Returns keys: tests, failures, errors, skipped, passed.
    `passed` is derived: tests - failures - errors - skipped.
    Raises OSError (missing file) / ET.ParseError (malformed) to the caller.
    """
    # Trusted source (pytest self-generates junit.xml in-job): stdlib etree is
    # fine. Switch to defusedxml if this ever parses an untrusted report.
    root = ET.parse(path).getroot()  # <testsuites> wrapper or bare <testsuite>
    totals = {"tests": 0, "failures": 0, "errors": 0, "skipped": 0}
    for suite in root.iter("testsuite"):
        for key in totals:
            totals[key] += int(suite.get(key, 0))
    totals["passed"] = (
        totals["tests"] - totals["failures"] - totals["errors"] - totals["skipped"]
    )
    return totals
```

# append to utils/junit_gate.py
def main(argv: list[str]) -> int:
    if len(argv) != 1:
        print("usage: junit_gate.py <junit.xml>", file=sys.stderr)
        return 2

    path = argv[0]
    try:
        counts = parse_junit(path)
    except (OSError, ET.ParseError) as exc:
        print(
            f"❌ gate FAIL (false green): no junit report — run produced no "
            f"result ({exc})",
            file=sys.stderr,
        )
        return 1

    print(
        f"report: {counts['tests']} collected · {counts['passed']} passed · "
        f"{counts['failures']} failed · {counts['errors']} errors · "
        f"{counts['skipped']} skipped"
    )
    ok, reason = evaluate_gate(counts)
    if ok:
        print(f"✅ gate PASS: {reason}")
        return 0
    print(f"❌ gate FAIL (false green): {reason}", file=sys.stderr)
    return 1


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```
